# Stadtrettung
Deutsch Echo — Stadtrettung ist ein actionreiches Lernspiel in einer von Monstern besetzten Stadt. Triff in 60 Sekunden die richtigen deutschen Wörter, sammle Schlüssel und befreie die Prinzessin. Jede Stufe wird schwerer, jeder Fehler zählt. Nur wer denkt und kämpft, kann die Stadt retten.
